Sales Management System

Project Description

The Sales Management System is a web-based application developed using Python and Flask.

It helps users manage products, sales, stock, and invoices in one place.

Features

- User Login
- Dashboard
- Product Management
- Stock Management
- Sales Management
- Daily, Weekly, Monthly, and Yearly Reports
- Invoice Management
- Low Stock Alerts

Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

Project Objective

The main objective of this project is to simplify sales tracking and stock management.
